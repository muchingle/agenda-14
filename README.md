### 2-2. 意思決定①｜PGTへの提携モデル

**論点：** PGTに対してどのような契約形態で営業をかけるか。

| 選択肢 | 概要 | メリット | デメリット |
|--------|------|---------|----------|
| **A. レベニューシェア型** | PGTが顧客紹介 → 成約時にツアー料金の15%をバック | PGT側リスクゼロ。導入ハードル低 | 当社取り分減少 |
| **B. 固定紹介料型** | 紹介1件につき固定額（例：5万円） | コスト予測しやすい | 高単価案件でPGTのインセンティブ弱 |
| **C. 業務委託型** | PGTを正式販売代理店として契約 | 継続送客が期待できる | 契約複雑。社内承認に時間 |

**山口推薦：A（レベニューシェア15%）**
PGT側リスクが低く、初回提携として受け入れられやすい。実績構築後にB/Cへの移行余地あり。

→ **佐々木氏のご判断をお願いします。**

### 2-3. 意思決定②｜LOTUS OCEANリカバリー方針

**論点：** ツアー提案は価格不成立だったが、提携意向は生きている。次の打ち手は。

| 選択肢 | 概要 |
|--------|------|
| **A. 提携スキーム提案に切り替え** | PGTと同様のレベニューシェア型提携を提案 |
| **B. 低価格プランで再提案** | 視察団向け1日10〜20万円のシンプルプランを再提案 |
| **C. 一旦保留** | 次回渡航時まで積極アプローチを控える |

**山口推薦：A**
紹介経由であり関係性を大事にしたい。提携が組めれば継続送客が見込める。

→ **佐々木氏のご判断をお願いします。**
