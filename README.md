### 2-1. 山口の仮説：PGTを「最初の送客パートナー」にする

この観光事業を動かすために、**PGT Holdingsを最初の送客パートナーにしたい**。以下がその理由と具体的な進め方についての山口の仮説。

#### なぜPGTか

- PGTは**上場企業**であり、ベトナムの企業・富裕層との既存の接点を持っている
- 旅行案内カウンター・ホテル運営など、**旅行需要のある顧客がPGTの周辺にいる**
- 社長（嘉数氏）が**日本人**であり、日本側サービスへの理解が早く、信頼構築がしやすい
- 自社でゼロから富裕層を探すより、**既に富裕層と接点のある企業から紹介を受ける方が効率的**

#### 提携モデル：PGTは「紹介するだけ」

PGTには営業もオペレーションも求めない。「日本に行きたいお客様がいます」という情報だけもらう。

**3者の役割分担：**

| 担当 | 拠点 | 役割 |
|------|------|------|
| **PGT Holdings** | ベトナム | 顧客紹介のみ。「日本旅行に行きたい」という顧客情報をHarry&に連携 |
| **山口（PM）** | マレーシア | 営業・ヒアリング・契約交渉・顧客対応・進捗管理 |
| **佐々木** | 京都 | ツアーの舞台組み・現地オペレーション・ガイド同行 |

山口はマレーシアに居住するため、日本現地でのツアー実施・同行は佐々木氏に担っていただきたい。

**送客フロー：**

```
PGT担当者「この方が日本旅行に興味があります」
  → 山口がヒアリング（予算・動機・人数・日程）
    → 佐々木氏と共有 → ツアープランを設計
      → 山口が提案・クロージング
        → 佐々木氏が京都で実施
```

#### 位置づけ：最初の一社、ここから横展開する

現時点で代理店（顧客を紹介してくれる会社）はどこも決まっていない。PGTを**最初の一社**として提携モデルを確立し、成功事例を作る。その後、LOTUS OCEAN等に同じスキームで横展開していく。

#### 契約形態と料率 — 佐々木氏に当てたい点

**契約形態の選択肢：**

| 選択肢 | 概要 | メリット | デメリット |
|--------|------|---------|----------|
| **A. レベニューシェア型** | 成約時にツアー料金の10〜15%をPGTにバック | PGT側リスクゼロ。導入ハードル低い | 当社取り分が減る |
| **B. 固定紹介料型** | 紹介1件につき固定額（例：5万円） | コスト予測しやすい | 高単価案件でPGTのインセンティブ弱い |
| **C. 業務委託型** | PGTを正式販売代理店として契約 | 継続送客が期待できる | 契約が複雑。上場企業の社内承認に時間がかかる |

**山口推薦：A（レベニューシェア型）**

PGTは「紹介するだけ」で営業もオペレーションも負担しない。この関係性では、成果報酬型が最もシンプルで導入しやすい。

**料率について：**

旅行業界の紹介手数料の相場は10〜20%。PGTは紹介のみで実務負担がないため、**10〜15%が妥当**と考えている。

| ツアー料金 | PGT取り分（10%） | PGT取り分（15%） |
|-----------|-----------------|-----------------|
| 30万円 | 3万円 | 4.5万円 |
| 50万円 | 5万円 | 7.5万円 |

ただし、この料率が適正かどうかは佐々木氏のご判断をいただきたい。実績が出てからB/Cに移行する余地もある。

→ **佐々木氏にご判断いただきたい点：**
1. **この仮説（PGTを最初の送客パートナーにする）の方向性は正しいか**
2. **契約形態：A / B / C のいずれか**
3. **料率：10〜15%の範囲で妥当か。具体的に何%が適正か**
